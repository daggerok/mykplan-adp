# mykplan-adp

Свой просмотрщик 401k из ADP mykplan: графики, доходность, взносы, прогноз до пенсии.
Данные собирает скрипт Tampermonkey в твоём Chrome, где ты сам входишь в mykplan. Сайт ADP только читается.

Открыть: https://daggerok.github.io/mykplan-adp

Ничего запускать на компьютере не нужно. Страница открытая, но твоих данных на ней нет: они хранятся только в твоём
браузере и в твоей Google-таблице

## Как пользоваться

### Один раз

1. Открой страницу выше и нажми ⚙️ справа вверху. Справа в настройках шаги **Get started**, галочки ставятся сами
2. **Доступ Tampermonkey.** Значок пазла справа от адресной строки -> Tampermonkey -> ⋮ -> **Manage extension** ->
   **Site access** -> добавить `https://daggerok.github.io/*`, `https://mykplan.adp.com/*` и `https://online.adp.com/*`
   (страница входа ADP, нужна для автоматического входа по 🔑)
3. **Скрипт.** В настройках нажми **Install script** -> в Tampermonkey **Install** -> обнови страницу
4. **Данные.** Нажми **Open mykplan**, войди. Справа внизу появится панель скрипта -> **🔄 Full**.
   Вкладку не закрывай около 30-40 минут, панель можно свернуть кнопкой **–**
5. Вернись на страницу: вкладки и графики появятся, когда данные соберутся. Пока идёт сбор, там видно шаг N из M

### После каждой зарплаты

На странице просмотра нажми **⬇** вверху справа (или на панели mykplan **⬇ Sync**): откроется mykplan, сбор
займёт около минуты, страница обновится сама. **🔄** там же - полный сбор, **⏹** - остановить. Если ты не вошёл,
войди (или скрипт войдёт сам по 🔑) - сбор начнётся после входа.

### Панель скрипта на mykplan

| Кнопка | Что делает |
|---|---|
| ⬇ Sync | только новое (счётчик `12/889 (+148 saved before)`: шаги этого сбора; уже сохранённое не скачивается заново) |
| 🔄 Full | всё, чего ещё нет; можно остановить, потом продолжит с того же места |
| ⏹ Stop / ▶ Continue | остановить после текущего шага / продолжить |
| 🔑 | по желанию: логин и пароль, чтобы скрипт сам входил снова, если сессия закончилась во время сбора. Хранятся только в хранилище Tampermonkey этого скрипта; код MFA вводишь ты |
| ↻ | проверить, что ты ещё вошёл в mykplan |
| – | свернуть панель в значок |
| строка `sheets: …` | записано ли в Google Sheets (время и сколько строк) или чего ждёт |
| {} JSON | скачать собранные данные |
| 📦 Raw | скачать все сохранённые страницы и PDF одним zip (для разработки: `bun run import-raw`) |

Если сессия закончилась: войди снова (или скрипт войдёт сам по 🔑), сбор продолжится сам.

Каждый сбор сверяет последний год с уже сохранёнными месяцами. Если ADP провёл операцию задним числом, на панели
и в уведомлении будет `ADP changed history from <дата>`: страницы с этой даты скачаются заново сами, делать ничего
не нужно. Дни до первого взноса пустые на сайте и не скачиваются.

### Google Sheets (по желанию)

Вкладки: `mykplan_tx` (транзакции), `mykplan_period` (итоги за периоды: месяцы, годы, по фондам и источникам,
YTD), `mykplan_daily` (каждый день по фондам и строка `Total` с NAV), `mykplan_election` (журнал заявок и проценты
после них). Старые вкладки `adp_*` от прежних версий можно удалить: страница их перечислит.

1. ⚙️ -> вписать Client ID и ссылку на таблицу (из `youtube/google.json`): сохраняются сами, скрыты точками, 👁 показывает, 📋 копирует не показывая
2. Дальше подключение само: при открытии страницы (или при первом клике на ней, если Chrome заблокирует окно Google)
   Google спросит доступ к таблицам. Не хочешь - отклони, до конца сеанса браузера не спросит; **☁️** подключает вручную

Дальше вкладки `mykplan_*` в таблице заполняются сами: во время сбора их пишет скрипт на mykplan каждые 50 шагов
и в конце, а страница просмотра дописывает то, что пришло, пока она открыта. Токен Google живёт около часа; пока
страница просмотра открыта, она продлевает его сама. Если токена нет, на панели mykplan видно
`sheets: waiting for ☁️ in the viewer`.

### Кнопки вверху страницы просмотра (как в twitter)

❓ что показывает открытая страница · 🇺🇸 EN или 🇷🇺 RU - язык (нажми, чтобы переключить) · ⚙️ настройки · 🐞 журнал (точки: скрипт, данные) · ⬇ Sync · 🔄 Full · ⏹ остановить сбор · ☁️ подключить Google ·
🔌 отключить Google · ↻ загрузить данные из таблицы (другой компьютер, без скрипта) · 📥 CSV транзакций · {} JSON
всех данных · тема. «Script update x.y.z →» - вышла новая версия скрипта: нажми и установи.

### Мои фонды против S&P 500 (экран Chart)

- **Performance** - доходность твоего выбора фондов, без влияния взносов
- **Value $** - счёт в долларах и голубая линия «All in SPY»: те же взносы в те же дни, но всё в SPY; над графиком
  разница на сегодня
- **vs SPY %** - столбик на каждую свечу: твоя доходность минус SPY за те же дни (зелёный - ты лучше), под графиком
  таблица по периодам
- Список **SPY ▾** меняет индекс сравнения; таблица фондов внизу: каждый фонд за свои дни против индекса

### Если что-то не так

- Вместо кнопки Install виден код скрипта, или нет панели на mykplan -> шаг 2 (Site access)
- Посмотреть без своих данных -> ⚙️ -> **Show demo data** (выдуманные цифры)
- 🐞 справа вверху: что собрано и какие строки скрипт не смог прочитать

## Разработка

Bun, React 19, Tailwind 4, lightweight-charts. Открытые репо на GitHub (Pages) и GitLab, `git push` уходит в оба.

```sh
bun install -E
bun test
bun run dev            # http://localhost:1234 (скрипт: /mykplan-adp-sync.user.js, демо: /dev/sample-dataset.json)
bun run build          # dist/ + dist/mykplan-adp-sync.user.js
bun run build:pages    # то же с путём /mykplan-adp/
bun run userscript     # только скрипт, с пересборкой
bun run import-raw     # ~/Downloads/mykplan-adp-raw-*.zip -> data/raw (ничего не перезаписывает)
```

- `userscript/` скрипт Tampermonkey: сбор (`src/crawl`: план -> запросы -> прогон с контрольными точками), панель,
  мост к вьюеру; на mykplan отправляются только формы-запросы, формы изменений запрещены в коде
- `shared/` ядро без UI: разбор страниц сайта, журнала и QFX, сборка набора данных, расчёты (TWR, XIRR, свечи,
  просадки, прогноз, Monte Carlo), бенчмарки (фиды daggerok.github.io), Google Sheets
- `src/` вьюер: `app` (данные, производные), `charts`, `ui/react` (экраны)
- `config/` значения по умолчанию и бенчмарки; `data/` сырые страницы и PDF только локально (в .gitignore)
